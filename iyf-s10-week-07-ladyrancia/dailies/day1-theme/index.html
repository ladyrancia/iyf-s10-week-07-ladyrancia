Theme Persistence Demo

About This Demo

This page demonstrates localStorage theme persistence. The theme preference (light/dark mode) is saved to localStorage and restored when you refresh the page.

Current theme: Light

Try It Out

1. Click the "Switch to Dark Mode" button

2. Refresh the page (F5 or Ctrl+R)

3. Notice the theme stays in dark mode

4. Clear localStorage to reset: localStorage.removeItem("theme")
