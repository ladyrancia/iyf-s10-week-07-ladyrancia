## Project Description

This project is a refactored To-Do List application that uses localStorage to persist data. It demonstrates JavaScript best practices, clean code structure, and state management.

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Local Storage API

## Features

* Add new todos
* Mark todos as completed
* Delete todos
* Data persists after page refresh
* Clean and organized code structure

## How to Run

1. Clone this repository
2. Open `index.html` in your browser

## Lessons Learned

* How to use localStorage to persist data
* Importance of JSON.stringify() and JSON.parse()
* Writing clean and maintainable JavaScript code
* Organizing code into reusable functions

## Challenges Faced

* Handling storage when empty
* Debugging localStorage issues
* Structuring code properly
